Proyecto: Calculadora de Subredes

Este repositorio contiene un proyecto básico en Python que resuelve un problema fundamental en el área de **Telemática y Redes**: el cálculo de parámetros de subredes IPv4.

¿Qué hace?
Permite ingresar una dirección IP con su notación CIDR (ej. `192.168.1.0/24`) y calcula automáticamente:
Dirección de Red y Broadcast.
Máscara de Subred y Wildcard.
Rango de hosts utilizables.

Por qué Telemática?
El entendimiento de cómo se segmentan las redes y cómo viajan los paquetes es la base de las telecomunicaciones modernas. Esta herramienta simula el análisis que un ingeniero en telemática realizaría para diseñar una infraestructura de red eficiente.
